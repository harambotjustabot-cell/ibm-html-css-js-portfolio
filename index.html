About Me

Ruel Tabernilla

I am a full stack developer who enjoys turning messy requirements into working software. I build Django and Node services, wire them to React front ends, and ship them with containers and CI/CD. Most recently I completed the IBM Full Stack Software Developer program, where I built a car dealership review portal end to end.

Project Details

Car Dealership Review Portal

A full stack app where customers browse dealerships, read reviews and post their own. Django serves the session-based UI, an Express API backed by MongoDB holds the dealership data, and a Flask microservice scores the sentiment of every review.

Django · React · Express · MongoDB · Flask

Containerised CI Pipeline

A GitHub Actions pipeline that lints the Python and JavaScript in separate jobs, builds the React bundle and gates merges on a green run. Images are built once and promoted between environments rather than rebuilt.

GitHub Actions · Docker · Kubernetes

Simple Interest Calculator

A small browser tool that computes simple interest from principal, rate and tenure, with sliders for rate and tenure and an input that refuses non-numeric principal values.

JavaScript · DOM · HTML5
